# AI生成画像基本チェック

AI で作った画像を esora の API でチェックする、ローカルで動くツールです。
Mac 専用です（画像の処理に macOS 標準の `sips` を使います）。

## 使い始める（初回だけ）

**社内ネットワークか VPN につないでから**始めてください。

1. **ZIP をダウンロード**: このページの緑の「Code」ボタン →「Download ZIP」。
2. **ZIP を解凍**: ダウンロードした ZIP をダブルクリック。
3. 解凍したフォルダの **`はじめに.html`** をダブルクリック（ブラウザで手順が開きます）。
4. 案内のとおりに進めます（初回だけ、「システム設定」で「このまま開く」を押します）。

手順の要点は次のとおりです。

1. フォルダの **`AICKtool.command`** をダブルクリック → 警告が出たら **「完了」**（ゴミ箱には入れない）。
2. **システム設定 → プライバシーとセキュリティ** を開き、いちばん下までスクロール。
3. 「"AICKtool.command"はブロックされました」の横の **「このまま開く」** を押す
   （パスワードか Touch ID。もう一度「開く」が出たら押す）。
4. 黒いウィンドウが開く。初回だけ「esora-api をインストールしますか？」と出たら `Enter`。
5. ブラウザが開いたら、右上の「サインイン」から Google でサインイン
   （サインインは 24 時間ごとにやり直しが必要です）。

## 2 回目から

`AICKtool.command` を**ダブルクリックするだけ**です。警告は出ません。

## 黒いウィンドウについて

ブラウザが開くと、黒いウィンドウは自動で **Dock にしまわれます**（動いたままです）。

## 終了するとき

Dock の「ターミナル」（しまわれたウィンドウ）をクリックして戻し、閉じます（または `Control + C`）。

## うまくいかないとき

| 症状 | 確認すること |
| --- | --- |
| 「このまま開く」が出ない | `AICKtool.command` をダブルクリックして警告を出してから、システム設定を開き直す |
| 「ゴミ箱に入れる」を押した | ZIP から、もう一度解凍する |
| 「esora-api をインストールできませんでした」 | 社内ネットワークか VPN につないでいるか |
| 「ポート 8765 を開けませんでした」 | ほかのアプリが使っています。そのアプリを閉じてください |
| サインインできない | VPN につないでいるか。それでも駄目なら esora 側の障害の可能性があります |

## ターミナルが使える方向け（任意）

ZIP の代わりに、ターミナルに次の 1 行を貼ると、`~/Applications/AICKtool.app` に入ります。
警告は出ません。次回からは `Command` + `スペース` →「AICKtool」で開けます。

```
curl -fsSL https://raw.githubusercontent.com/yasuyuki-uehara/esora_Photo_Check/main/install.sh | bash
```

## フォルダの中身（開発者向け）

| 名前 | 役割 |
| --- | --- |
| `AICKtool.command` | **これを開く**（起動用） |
| `はじめに.html` | 初回の手順（ブラウザで開く） |
| `Contents/` | プログラム本体 |
| `install.sh` | ターミナル向けインストーラー |
| `build/` | 入口バイナリのソース |

- `Contents/Resources/launch.sh`: 必要なものを確認して、サーバーを起動し、ブラウザを開きます
- `Contents/Resources/app/server.py`: `http://127.0.0.1:8765/` で動くローカルサーバー（自分の Mac の中でだけ動きます）
- `Contents/Resources/app/check_image.py`: esora の API に画像を送って、チェック結果を受け取ります

開発のときは、`python3 Contents/Resources/app/server.py` で直接起動できます。
