# AI生成画像基本チェック

AI で作った画像を esora の API でチェックする、ローカルで動くツールです。
Mac 専用です（画像の処理に macOS 標準の `sips` を使います）。

## 導入（初回だけ）

1. **ZIP をダウンロード**: GitHub のこのページで、緑の「Code」ボタン →「Download ZIP」。
2. **ZIP を解凍**: ダウンロードした ZIP をダブルクリック。
3. 解凍したフォルダの **`はじめに.txt`** を開く（普通のテキストなので警告は出ません）。
4. **`AICKtool.command` を右クリック →「開く」→「開く」**  
   （ダブルクリックだと「ゴミ箱に入れる」「完了」だけの警告になり、進めません）

※ 使うのはフォルダ直下の **`AICKtool.command`** だけです。  
  `Contents` フォルダはプログラム本体です（普段は触らなくて大丈夫です）。

初回は次のことが起きます。

- 「esora-api をインストールしますか？」と聞かれたら、`Enter`（はい）を押します。
  社内ネットワークか VPN につないでおいてください。数分かかることがあります。
- ブラウザが自動で開きます。右上の「サインイン」を押して、Google でサインインします
  （サインインは 24 時間ごとにやり直しが必要です）。

## 2 回目から

`AICKtool.command` をダブルクリックするだけです（一度「開く」で通したあと）。
すでに起動しているときは、ブラウザだけが開きます。

## 終了するとき

起動で開いた黒いウィンドウを閉じます（または `Control + C`）。

## 警告が出たとき（「ゴミ箱に入れる」「完了」だけ）

GitHub から落としたファイルには、macOS が「確認できていない」印を付けます。
Apple の有料署名・公証がないアプリでは、次の画面が出るのが普通です（壊れていません）。

- 「〜は開いていません」「マルウェアを検証できませんでした」
- ボタンが「ゴミ箱に入れる」「完了」だけ（ここに「開く」は出ません）

**いま開く手順**

1. **「完了」** を押す（ゴミ箱には入れない）。
2. **`AICKtool.command` を右クリック →「開く」→「開く」**。  
   こちらだと「開く」ボタン付きの確認が出ます。
3. それでも駄目なら `はじめに.txt` の「方法 B」（ターミナルで印を外す）へ。

## うまくいかないとき

| 症状 | 確認すること |
| --- | --- |
| 「ゴミ箱に入れる」「完了」だけの警告 | 「完了」→ `AICKtool.command` を右クリック→「開く」 |
| 「esora-api をインストールできませんでした」 | 社内ネットワークか VPN につないでいるか。インターネットにつながっているか |
| 「ポート 8765 を開けませんでした」 | ほかのアプリが使っています。そのアプリを閉じてください |
| サインインできない | VPN につないでいるか。それでも駄目なら esora 側の障害の可能性があります |

起動に失敗したときのログは `~/Library/Logs/AICKtool.log` に残ります。

## フォルダの中身

| 名前 | 役割 |
| --- | --- |
| `AICKtool.command` | **これを開く**（起動用。アプリアイコン付き） |
| `はじめに.txt` | 初回の開き方 |
| `Contents/` | プログラム本体（普段は触らない） |
| `build/` | 開発用（入口バイナリのソース） |

## 仕組み

プログラムは `Contents/Resources/app` にあります。

- `Contents/Resources/launch.sh`: 必要なものを確認して、サーバーを起動し、ブラウザを開きます
- `Contents/Resources/app/server.py`: `http://127.0.0.1:8765/` で動くローカルサーバー
- `Contents/Resources/app/check_image.py`: esora の API に画像を送って、チェック結果を受け取ります
- `Contents/Resources/AICKtool.icns`: `AICKtool.command` 用のアイコン

開発のときは、`python3 Contents/Resources/app/server.py` で直接起動できます。
