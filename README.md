# AI生成画像基本チェック

AI で作った画像を esora の API でチェックする、ローカルで動くツールです。
Mac 専用です（画像の処理に macOS 標準の `sips` を使います）。

## 導入（初回だけ）

1. **ZIP をダウンロード**: GitHub のこのページで、緑の「Code」ボタン →「Download ZIP」。
2. **ZIP を解凍**: ダウンロードした ZIP をダブルクリック。
3. **`AICKtool` をダブルクリック**: 解凍したフォルダの中にあります（`AICKtool.app`）。

初回は次のことが起きます。

- 「開いてよいか確認できません」と出ることがあります。下の「初回に警告が出たとき」を見てください。
- 「esora-api をインストールしますか？」と聞かれたら、`Enter`（はい）を押します。
  社内ネットワークか VPN につないでおいてください。数分かかることがあります。
- ブラウザが自動で開きます。右上の「サインイン」を押して、Google でサインインします
  （サインインは 24 時間ごとにやり直しが必要です）。

## 2 回目から

`AICKtool` をダブルクリックするだけです。ブラウザが開きます。
すでに起動しているときは、ブラウザだけが開きます。

## 終了するとき

`AICKtool` で開いた黒いウィンドウを閉じます（または `Control + C`）。

## 初回に警告が出たとき

ダウンロードしたファイルには、macOS が「確認できていないファイル」の印を付けます。
そのため、初回だけ「開けません」と出ることがあります。次のどちらかで開けます。

- **macOS 15 以降**: 警告が出たら「完了」を押し、「システム設定」→「プライバシーとセキュリティ」を開き、
  下のほうの「`AICKtool` はブロックされました」の横の「このまま開く」を押します。
- **macOS 14 以前**: `AICKtool` を右クリック（Control + クリック）→「開く」→「開く」。

どちらでも開けないときは、「ターミナル」で、解凍したフォルダに次を実行してから、もう一度ダブルクリックします
（`フォルダのパス` は、フォルダをターミナルにドラッグすると入ります）。

```
xattr -dr com.apple.quarantine フォルダのパス
```

## うまくいかないとき

| 症状 | 確認すること |
| --- | --- |
| 「esora-api をインストールできませんでした」 | 社内ネットワークか VPN につないでいるか。インターネットにつながっているか |
| 「ポート 8765 を開けませんでした」 | ほかのアプリが使っています。そのアプリを閉じてください |
| サインインできない | VPN につないでいるか。それでも駄目なら esora 側の障害の可能性があります |

## 仕組み

プログラムはすべて `AICKtool.app` の中（`Contents/Resources/app`）にあります。
ダウンロードしたアプリは、macOS が別の場所に仮想的に移して動かすことがあるため、
アプリの外にファイルを置かない作りにしています。

- `Contents/MacOS/AICKtool`: アプリの入口。ターミナルで起動処理を開きます。
- `Contents/Resources/launch.sh`: 必要なものを確認して、サーバーを起動し、ブラウザを開きます。
- `Contents/Resources/app/server.py`: `http://127.0.0.1:8765/` で動くローカルサーバーです。自分の Mac の中でだけ動きます。
- `Contents/Resources/app/check_image.py`: esora の API に画像を送って、チェック結果を受け取ります。

開発のときは、`python3 AICKtool.app/Contents/Resources/app/server.py` で直接起動できます。
